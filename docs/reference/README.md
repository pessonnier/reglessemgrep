# Documentation de référence et normes

Ce dossier regroupe les références utilisées pour interpréter les catalogues. Ajoutez ici des **liens, versions, dates de consultation et notes de correspondance**. N’y copiez pas le texte intégral d’une norme ou d’un catalogue sans en vérifier les droits.

| Référence | Source officielle | Utilisation actuelle |
|---|---|---|
| CAST Rules | [Site actuel](https://technologies.castsoftware.com/) · [ancien Swagger](https://technologiesv1.castsoftware.com/swagger-ui/) | Identifiants, technologies, critères et standards publiés |
| Semgrep Community Rules | [Dépôt Git](https://github.com/semgrep/semgrep-rules) · [syntaxe des règles](https://semgrep.dev/docs/writing-rules/) | YAML, métadonnées et commit source |
| CWE | [Catalogue MITRE](https://cwe.mitre.org/data/index.html) | Identifiants CWE explicitement déclarés |
| OWASP Top 10 | [Édition 2021](https://top10.owasp.org/2021/) | Catégories OWASP explicitement déclarées |
| ISO/IEC 5055 | [Fiche officielle ISO](https://www.iso.org/standard/80623.html) | Références présentes dans CAST lorsque publiées |
| Semgrep Rules License | [Texte officiel](https://semgrep.dev/legal/rules-license/) | Conditions de conservation et de redistribution |

Date de consultation initiale : 26 octobre 2026. Toute nouvelle correspondance entre référentiels doit conserver sa source et sa date, et préciser si elle provient de l’éditeur ou d’une interprétation locale.
